# 情報リテラシ研修サイト

`content/` のMarkdownからPowerShell 7の標準変換機能で静的HTMLを生成します。メンバー用簡易ゲートの通過にはJavaScriptが必要です。`lesson.js` は目次からの自動展開、一括開閉、印刷時の本文展開を補助します。外部サービスは不要です。

## 更新方法

1. `content/` 内の原稿を更新します。別フォルダで管理する場合は更新した原稿をコピーしてください。
2. リポジトリのルートで `pwsh -NoProfile -File members/itlit/build.ps1` を実行します。
3. 生成したトップ・各章のHTMLを確認し、原稿と一緒にコミットします。

章名はファイル名から取得します。Obsidianの章リンクをHTMLリンクへ変換し、章内目次と前後の章へのリンクを生成します。`確認の解答.md` は章ごとに分け、各章末の折りたたみ欄へ掲載します。解答は章単位で原稿の順序を保ちます。

HTMLの直接編集は再生成時に上書きされます。構成は `build.ps1`、見た目は `styles.css` で変更してください。原稿の校閲・事実確認は変換処理には含まれません。

PCの目次は本文スクロールに追従し、長い目次は項目部分だけスクロールします。本文は見出し階層を保った折りたたみ構造で、初期表示はすべて開いています。スマートフォンでは目次を本文の上に配置します。
